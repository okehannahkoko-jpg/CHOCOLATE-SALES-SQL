# Chocolate Sales Data Analysis Using SQL

## About the Project

This project involved working with a chocolate sales dataset using MySQL Workbench. I used SQL queries to explore the data and answer questions about sales performance, products, salespeople and countries.

The project gave me an opportunity to practise writing SQL queries and understand how data can be used to examine business performance.

## Dataset

The dataset contains sales records with the following columns:

- Sales Person
- Country
- Product
- Date
- Amount
- Boxes Shipped

## Tools Used

- **MySQL Workbench:** Used to write and execute SQL queries.
- **CSV:** Used as the source dataset.

## What I Worked On

During the analysis, I used SQL to:

- Check the dataset for missing values.
- Rename columns to make them easier to work with.
- Calculate total revenue.
- Calculate the total number of boxes shipped.
- Find the average revenue per box.
- Identify the top 10 products by revenue.
- Find the products with the highest and lowest revenue per box.
- Compare revenue generated by different salespeople.
- Analyse the number of boxes shipped by each salesperson.
- Examine revenue and boxes shipped across different countries.

## SQL Skills Practised

- SELECT statements
- WHERE clause
- IS NULL
- ALTER TABLE
- RENAME COLUMN
- Aggregate functions (SUM)
- GROUP BY
- ORDER BY
- LIMIT
- Column aliases

## What I Learned

Working on this project helped me become more familiar with SQL and how to use queries to retrieve and analyse information from a dataset.

I also gained more practice in grouping data, calculating totals, sorting results and comparing sales performance across different categories.

## Conclusion

This was a good opportunity to put my SQL learning into practice using a chocolate sales dataset. It helped me build confidence in writing queries and strengthened my understanding of how SQL can be used to answer business-related questions.
